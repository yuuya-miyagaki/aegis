- [confidence:9] シェルコマンドの control-plane 判定を「正規表現＋クォート span マスク」でやると、シェルの**クォート除去＋隣接トークン連結**（`hooks""/lib`→語 `hooks/lib`）を再現できず分割トークン書込みを取りこぼす。正しくは**語単位にトークン化→各語の literal value を再構成→書込み先語のみ判定**。詳細・OPEN 課題は `docs/security-followups.md` SF-001。

- [confidence:9] **`os.chmod` は symlink を辿る**（`chmod -R` シェルコマンドは BSD 既定で**辿らない**＝両者は非対称）。テストが実リポのファイルを scratch に **symlink** し、その scratch が session-start の `aegis_cp_lock` で `chmod -R a-w` され、`with tempfile.TemporaryDirectory()` 終了時の `rmtree` が locked dir で `PermissionError` を起こすと、Python stdlib の **`resetperms` onerror ハンドラが `os.chmod(path, 0o700)` を実行**＝symlink を辿って**実ファイルを 0o700 化**する（iteration 35 の「check_status.py 700 化」の真因。当初 cp-lock の chmod -R 追従を疑ったが直接プローブで反証）。教訓: テスト scratch に**実リポファイルを symlink しない（copy する）**／lock する scratch は cleanup 前に unlock する。再現特定は `pytest_runtest_logfinish` で対象 mode を監視する conftest が有効（1 回 1 件検出なので全件直すまで反復）。
